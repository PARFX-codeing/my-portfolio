# 🌟 Shaxsiy Bio & Ijtimoiy Tarmoqlar Sayti

Zamonaviy dizaynga (Glassmorphism & Cyber Glow) ega bo'lgan shaxsiy vizitka / bio-havolalar veb-sayti.

## 📁 Fayllar Tuzilishi
- `index.html` — Saytning skeleti va ma'lumotlar qismi.
- `style.css` — Dizayn, ranglar, animatsiyalar va mobil moslashuvchanlik (responsive).
- `script.js` — Dinamik salomlashuv, Dark/Light rejim, havolani nusxalash va filtrlash.

---

## 🛠️ Qanday Qilib O'zingizga Moslashtirish Kerak?

1. **`index.html` faylini oching**:
   - `Ismingiz Familiyangiz` o'rniga o'z ism-familiyangizni yozing.
   - `profile-tagline` va `about-text` bo'limiga o'zingiz haqingizda qisqacha ma'lumot yozing.
   - `href="https://t.me/username"` kabi qismlarga o'zingizning haqiqiy Telegram, Instagram, YouTube, Steam va GitHub manzillaringizni kiriting.
   - `img src="..."` qismiga o'z fotosuratingiz havolasini yoki loyihaga rasm qo'shib uning nomini yozing.

## 🚀 GitHub-ga Yuklash va Saytni Internetda Ochish (GitHub Pages)

### 1-qadam: Git orqali kompyuterdan saqlash
Terminalda loyiha papkasida quyidagi buyruqlarni bajaring:
```bash
git init
git add .
git commit -m "Ilk versiya: Mening shaxsiy bio saytim"
```

### 2-qadam: GitHub-da yangi repozitoriy yaratish
1. [GitHub](https://github.com) ga kiring.
2. Yuqori o'ng burchakdagi **`+`** belgisini bosib **"New repository"** ni tanlang.
3. Repozitoriy nomini yozing (masalan: `my-portfolio` yoki `links`).
4. **Public** rejimini tanlang va **Create repository** tugmasini bosing.

### 3-qadam: Kodni GitHub-ga yuklash
GitHub sahifasida chiqqan buyruqlarni terminalingizga yozing:
```bash
git branch -M main
git remote add origin https://github.com/SIZNING-GITHUB-USERNAME/my-portfolio.git
git push -u origin main
```

### 4-qadam: GitHub Pages orqali saytni jonlantirish (Live qilish)
1. GitHub-dagi repozitoriyingizga kiring.
2. Yuqoridagi **Settings** (Sozlamalar) bo'limiga o'ting.
3. Chap menyudan **Pages** bo'limini tanlang.
4. **Branch** qismida `None` o'rniga `main` ni tanlang va **Save** tugmasini bosing.
5. Bir-ikki daqiqadan so'ng sizga shaxsiy veb-sayt havolasi beriladi:
   `https://SIZNING-USERNAME.github.io/my-portfolio/`

Tabriklaymiz, saytingiz butun dunyo uchun ochiq va jonli ishlaydi! 🎉
